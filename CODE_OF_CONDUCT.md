# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and keep discussion on the work.

To report unacceptable behaviour, contact the maintainer privately through the repository's
[security advisory form](https://github.com/VadimBabich/entity-metamodel-workspace/security/advisories/new),
which is private to the maintainer. Reports are handled confidentially.
